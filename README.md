# Mohammadmahdi Azizmohammadi — Portfolio

Production source for https://portfolio.azizmohammadii.ir/

## Structure
- `index.html` — English
- `index-fa.html` — Persian
- `portfolio.css` — shared visual system
- `portfolio.js` — interaction, deck and case views
- `assets/deck/web/` — project imagery
- `assets/fonts/` — local Dana files (not committed by automation; upload licensed files manually)
